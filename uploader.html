피키대디 업로더

PickyDaddy Uploader — 개인용 유튜브 업로드 도구

YouTube API 서비스를 사용합니다 · Uses YouTube API Services

유튜브 채널 월급쟁이 피키대디 운영자가 만든 쇼츠 영상을, 운영자가 직접 확인하고 승인한 뒤 운영자 본인의 채널에 올리는 개인용 프로그램입니다. 운영자 PC에서만 실행되며 다른 사용자는 없습니다.

하는 일

  1. 운영자가 구글 계정으로 한 번 허용합니다(OAuth 2.0).
  2. 운영자가 완성된 영상을 확인하고 '승인'합니다.
  3. 앱이 영상·제목·설명·썸네일을 운영자 채널에 비공개로 올립니다.
  4. 운영자가 YouTube 스튜디오에서 확인한 뒤 직접 공개합니다.

What it does (English)

A private desktop tool used only by the owner of the YouTube channel "월급쟁이 피키대디". After the owner signs in with Google (OAuth 2.0) and manually approves a finished Short, the tool uploads the video, title, description and thumbnail to the owner's own channel as private. The owner then reviews it in YouTube Studio and publishes it manually. No other users, no data sharing.
